# Projeto: Banco de Dados Relacional com SQL Procedural

Este projeto demonstra a criação de um banco de dados relacional com uso de SQL procedural e otimização com índices.

## Objetivos
- Criar tabelas relacionadas (Departamento e Empregado)
- Criar índices para melhorar performance
- Utilizar procedures para inserção e atualização de dados
- Executar consultas analíticas

## Estrutura
- estrutura.sql: criação das tabelas e índice
- dados_e_consultas.sql: inserção de dados e consultas
- procedures.sql: procedures e testes
